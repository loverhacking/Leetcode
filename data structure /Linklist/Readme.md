# 刷题记录

## 链表翻转
* `ReverseList`: 翻转链表 
* `reverseBetween`: 链表内指定区间反转
* `reverseKGroup`: 链表中的节点每k个一组翻转

## 链表合并
* `Merge.cpp`:合并两个排序的链表
* `MergeKLists.cpp`:合并k个排序链表

## 链表有环
*  `hasCycle.cpp`:判断链表中是否有环
* `EntryNodeOfLoop.cpp`:链表中环的入口结点

## 链表倒数节点
* `FindKthToTail`: 链表中倒数最后k个结点
* `removeNthFromEnd`: 删除链表的倒数第n个节点

## 链表公共节点
`FindFirstCommonNode`: 两个链表的第一个公共结点

## 链表相加
`addInList`: 链表相加-II

## 链表排序
`sortInList`: 链表排序

## 判断链表是回文结构
`isPail`: 判断链表是回文结构 

## 链表奇偶重排
`oddEvenLis`:链表奇偶重排

## 删除有序链表重复元素
`deleteDuplicates1`: 删除有序链表重复元素(重复元素保留1位) 
`deleteDuplicates2`: 删除有序链表重复元素(重复元素不保留)
